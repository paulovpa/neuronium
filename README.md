# Neuronium
 
Descubra a magia por trás da minha mente através da neurociência comportamental.
 
## Sobre o projeto
 
Neuronium é um site dinâmico que mistura **neurociência comportamental** com o **universo mágico de Harry Potter**. 
A proposta é apresentar a minha própria jornada de autoconhecimento, de forma leve, visual e interativa, abordando como o cérebro cria, molda e transforma hábitos, utilizando elementos inspirados na minha saga favorita para entender como ambos os conceitos se conectaram e transformaram a minha forma de enxergar o mundo.

O que mudou a minha vida não precisa ficar só comigo: este projeto é um convite para que outras pessoas também descubram o poder de entender o próprio cérebro.
